# Dev Flow 文档国际化策略

[中文](I18N.md) | [English](I18N_en.md)

## 适用范围

本策略管理仓库中的人类可读文档，不定义产品运行时 locale。产品行为权威仍是源码、机器可读
Schema、制品清单和可执行测试；翻译文件只负责以不同语言准确呈现同一组事实。

## 维护语言

根 README 维护以下 9 个 locale：

| Locale | 语言 | 文件 | 角色 |
| --- | --- | --- | --- |
| `zh-CN` | 简体中文 | `README.md` | 仓库默认入口与中文版本 |
| `en` | English | `README_en.md` | 英文版本；其他非中文翻译的 source text |
| `zh-TW` | 繁體中文 | `README_zh-TW.md` | 完整维护 |
| `ja` | 日本語 | `README_ja.md` | 完整维护 |
| `ko` | 한국어 | `README_ko.md` | 完整维护 |
| `es` | Español | `README_es.md` | 完整维护 |
| `fr` | Français | `README_fr.md` | 完整维护 |
| `de` | Deutsch | `README_de.md` | 完整维护 |
| `pt-BR` | Português do Brasil | `README_pt-BR.md` | 完整维护 |

新增 locale 必须同时提供完整初始翻译、语言导航入口和后续维护责任。不得先添加空文件、占位链接
或只翻译标题。

## 文档覆盖矩阵

| 文档族 | 维护范围 |
| --- | --- |
| 根 `README*` | 上述全部 9 个 locale，结构和产品事实必须一致 |
| `docs/PRODUCT*`、`docs/ARCHITECTURE*`、`docs/ROADMAP*`、`docs/SUPPORT-MATRIX*`、`MANIFEST*` | 简体中文与英文 |
| Codex / DeepSeek 用户与安装文档 | 当前维护的简体中文与英文配对文件 |
| `CONTRIBUTING*` 与 I18n 策略 | 简体中文与英文 |
| Constitution、`AGENTS.md`、Feature、release 和 maintainer 合同 | 按各自权威语言维护；除非已有明确配对，不自动复制为 9 语种 |

覆盖范围是显式合同，不根据目录名称自动推断。某个文档族一旦列出多个 locale，任何事实性修改都
必须同步该文档族的全部维护文件。

## 同步合同

任何改变用户可见行为的 Product Feature 必须在同一 Pull Request 中：

1. 更新全部 9 个根 README；
2. 更新 `docs/PRODUCT.md` 与 `docs/PRODUCT_en.md`；
3. 按影响面更新 Architecture、Support Matrix、Roadmap、Host package README、安装或调用文档；
4. 在 `tasks.md` 和 Pull Request 验证说明中列出所有文档路径。

版本发布改变公开版本、bundled Core、平台、Host 兼容范围、安装命令或 release evidence 时，也
必须在发布前同步所有根 README 以及受影响的支持与 package 文档。

纯文档修正必须修改所有包含同一错误陈述的维护 locale。翻译尚未同步时，不得把 Product Feature、
文档变更或 release 状态报告为可合并、Complete 或 ready to publish。

## 翻译不变量

所有 locale 必须保持以下内容一致：

- 命令、selector、工具名、环境变量、路径和文件名；
- 产品版本、bundled Core、平台与 Host 兼容范围；
- Node、Transition、错误码、Schema、Recovery classification 和技术标识符；
- 表格行、代码块、Mermaid 图、链接目标和支持声明；
- 能力、非目标、限制和验证证据的含义。

只翻译叙述性文字。没有稳定译法的标识符保留英文，不为不同 locale 发明不同的产品术语或额外
承诺。翻译可以调整语序和句式，但不能扩大、缩小或重新解释产品行为。

## 审查要求

文档或产品 Pull Request 至少检查：

- 语言导航中的每个文件存在且互相可达；
- 新增、删除或移动的章节在全部根 README 中一致；
- 版本、命令、平台和 Support Matrix 声明没有漂移；
- 非英文 README 没有残留占位文本或整段英文 fallback；
- 技术参考的中英文配对文件表达同一事实。
