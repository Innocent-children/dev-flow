# 桌面宠物验收

[中文](validation.md) | [English](validation_en.md)

验收检查[方案](plan.md)的功能、[技术设计](design.md)的连接与生命周期，以及
[界面与动画规格](ui-design.md)要求的精美成品。最终对象是随统一入口 npm tarball 安装的
`DevFlowPet.app`，包括其正式素材、签名和语言资源。

当前按用户的功能优先要求执行：以本地开发包的任务展示、交互、连接与生命周期为完成条件。
V06 的视觉精修、V07 的动画流畅度和长时间性能录屏、V11 的正式公证及 V12 的完整 Host 会话测试
不属于本次检查。下文保留整体场景定义，实际执行范围见文末记录；单元样例与原生操作分别记录。

## 环境与准备

在 macOS arm64 上准备可隔离的 Dev Flow 测试安装和任务数据。记录实际 macOS、硬件、显示器缩放、
Node.js、Swift/Xcode、Codex/DeepSeek、统一入口与 Adapter 的版本及安装包 SHA-256。
精确产品版本只写入实现阶段的机器可读运行记录，不写入面向用户的安装说明。

T01 首先核验最低系统/构建范围、Developer ID 签名身份、公证凭据引用与构建机。实际验证之前，
最低 macOS 与 Swift/Xcode 版本保持待核验，不用开发机版本代替最低版本。凭据引用可以记录，密钥不记录。

准备以下条件：

- 无 Adapter、仅 Codex、仅 DeepSeek、两者共存的安装组合；
- 独立任务数据目录和不同数据目录下的选择记录；
- 普通、受阻、完成、取消、归档和不存在的任务，以及超过 50 条任务的分页样例；
- 可注入延迟、404、失败及重定向的 HTTP 测试端点，仅供定向客户端测试；
- 真实的动态端口 WebUI 服务、浏览器、浅色/深色/复杂桌面背景与系统减少动态效果设置。

状态样例验证展示规则；实际 Host 流程验证产品接入。测试端点和样例不得记为真实 Core 或 Host 运行。

| 检查位置 | 覆盖内容 |

| `packages/desktop-pet/macos/Tests/`（新增） | HTTP 解码、迟到响应、连接恢复、显示优先级与动画触发 |

## 场景步骤与通过条件

### V01 激活条件与命令

在四种 Adapter 安装组合下分别调用拟新增的 `dev-flow pet start`，并从交互菜单重复。
无可用 Adapter 时提示安装、返回失败，没有宠物窗口；其余组合使用现有选择规则成功开启，
不要求 Codex 和 DeepSeek 同时安装。失败不会自动安装 Adapter。

检查未知子命令、额外参数和 Windows x64 的直接调用，分别返回参数或平台错误。
`pet status` 与 `pet start --json` 不作为受支持接口。其他现有 Windows 命令保持可用，
这里只运行入口相关定向测试，不声明支持 Windows 宠物。

### V02 关注对象与分页

没有偏好时按 blocked、active 顺序检查默认选择；两者为空显示待机。保存选择后重新开启，
恢复同一 `data_root_digest` 的任务。完成后的任务仍被关注，其他任务更新不会切换它。

打开选择面板，翻过 50 条样例的第一页，直到 `has_next=false`。检查选择标记、来源 Host、
阶段和仓库提示；面板关闭后不继续翻页。保存的任务不存在时明确提示，由用户重新选择。

### V03 阶段、受阻与终态

依次观察普通节点前进、回退、进入 BLOCKED、阻塞文本改变、恢复、进入 DONE。
阶段与 Core 相同；阻塞文本正确；相同状态的 revision 增加不重播提示。
进入 DONE 只庆祝一次，随后静止；另用独立任务验证 CANCELLED 不庆祝。

分别直接打开已完成任务、从隐藏/唤醒/断线恢复至已完成任务、切换到已完成任务：
全部直接显示完成姿态，不重放历史庆祝。首次读取受阻任务进入安静循环。
普通工作主题动画不配“Host 正在执行”等无法由 Core 确认的文案。

### V04 连接失败与恢复

停止实际 WebUI，检查气泡变为未连接、旧信息标为上次记录、工作/庆祝动作取消并切换未连接动画。
后台仅每 15 秒检查，不能自动反复重启服务。由用户重试可调用 start；
服务自行恢复时也能重新取得地址并恢复读取。

用定向样例验证 404、只读、归档、服务身份不符、HTTP 失败及重定向。404 与归档不被当成断线；
只读保留阶段；错误身份和重定向不能用于跳转。改变 Core 身份或移除其路径后，宠物退出，
下次由入口重新选 Adapter。

### V05 迟到响应与导航

让 A 任务响应延迟，在其返回前切到 B；让旧连接响应延迟，再建立新连接。
迟到结果不得覆盖 B 或新连接，也不得播放 A 的庆祝。翻页和关闭面板同样取消过期列表结果。

重启 WebUI 使端口变化，再点击宠物，浏览器必须进入新 origin 上的准确任务详情。
拖动超过阈值后松开不打开页面；任务不存在时点击进入列表。浏览器打开失败保留当前画面并允许重试。

### V06 原创形象与完整动画

核对 `idle/working/blocked/complete/disconnected` 五类素材，每类都有完整动作、静态帧及预览。
逐项执行界面规格的造型、透明边缘、缩放、动作层次和循环检查；循环连续观看至少五轮。

在实际应用内切换状态，检查待机、专注、受阻反应、庆祝起势/主体/收势和未连接反应。
记录浅色、深色、复杂背景及 `96 / 144 / 192 pt` 检查画面。
任意一类被占位图、纯静态图片或整图晃动代替，均判为未完成。

### V07 转场、动态效果与常驻表现

在动作进行中切换任务、改变连接和关闭动画；旧动作立即取消，文字及时更新，角色锚点稳定，
新动作衔接自然。开启系统减少动态效果，所有状态使用各自静态帧；再次启用动画不补播事件。

在最终安装包上观察待机和普通阶段各 5 分钟，再隐藏 2 分钟。记录 CPU、内存和实际 HTTP
响应体大小/耗时；通过条件是周期请求没有堆积、内存没有随循环持续增长、隐藏期间没有动画
计时或轮询、拖动和其他桌面应用使用流畅。该检查不使用未经测量的固定 CPU/内存数字替代结果，
也不通过缩减必需动画来达标。

### V08 原生窗口与双语界面

用编辑器持续输入时触发更新、受阻和完成，确认没有丢失键盘焦点。检查点击、拖动、悬停、
右键、菜单栏、键盘选择任务、隐藏/显示和退出。

分别检查普通桌面、Space 切换、一个全屏应用与外接显示器移除。记录系统实际表现；
窗口不能永久丢在不可见屏幕，用户可返回菜单栏恢复或退出。检查中文/英文系统偏好、长任务名、
长路径和长阻塞文本，确保不溢出或缩成难以阅读的小字。

### V09 单实例与维护 Adapter

连续和并发触发开启，确认只出现一个宠物。隐藏后再次开启恢复显示；另一数据目录或 Core
身份的开启提示先关闭，不改变已有关注对象。关闭后无窗口/菜单栏残留，WebUI 和任务仍存在。

对当前供给 Core 的 Adapter 执行统一入口的升级、修复、重装和卸载路径，确认先停止宠物。
定向注入停止失败，后续移除必须中止。只读预览、未确认操作、维护其他 Adapter 不停止它。
验证外部移除在后续检查中被发现；保留的另一 Adapter 可在下次开启时被选中。

### V10 偏好与 reset

调整位置、关注对象和动画开关，退出后重新开启，应恢复这些偏好。普通卸载保留偏好。
检查不同数据目录的关注对象各自保存，系统语言不产生新的配置字段。

确认 reset 计划明确包含宠物目录，停止宠物成功后按现有 Trash 或永久删除流程清理。
缺少必要确认时不得清理，停止失败也不得继续；不扩大显式数据目录的既有授权。

### V11 最终 npm 包

从与正式分发相同的 staging 生成 tarball，在隔离前缀安装，使用安装后的入口开启宠物。
安装前缀包含空格；运行过程中不依赖仓库目录或构建机上的资源文件。普通用户无需 Swift/Xcode。

核对应用只携带一份、五类动画及语言文件齐全、所有引用可解析、权限有效；在解包后的应用上执行
macOS 签名与公证票据检查，并实际启动。确认用户的正常安装路径不要求绕过系统安全检查。
升级统一入口前先停止宠物，更新后重新开启使用新包内容；卸载遵循已说明的保留偏好规则。

### V12 实际 Host 流程与文档

在实际 Codex 中完成一个 Dev Flow 任务的阶段推进、受阻、恢复和完成，观察所选任务的画面和跳转。
在实际 DeepSeek 中创建并推进任务，验证读取、选择、状态更新和跳转；两者共存时使用同一数据目录。

核对方案列出的产品文档和全部维护语言，确认安装、两项新命令、Adapter 前提、平台及动画说明
与最终安装包一致。产品文档更新在功能实现时进行，不能将本次文档完成写成产品已交付。
