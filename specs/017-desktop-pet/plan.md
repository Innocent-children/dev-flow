# Dev Flow 桌面宠物方案

[中文](plan.md) | [English](plan_en.md)

开发者可以在桌面上查看所关注 Dev Flow 任务的阶段，任务受阻或完成时看到提示，点击宠物进入该任务的
WebUI。宠物是随 `@imotong/dev-flow` 分发的 macOS arm64 原生组件；安装并配置好任意一个 Codex
或 DeepSeek Adapter 后，用户才能开启它。宠物读取已有 Core 数据，两种 Host 使用相同的展示规则。

本次按 2026-09-06 的用户要求，以功能可用为交付目标：启动与关闭、任务选择和阶段展示、WebUI 跳转、
连接恢复、隐藏与唤醒、偏好和 Adapter 维护，以及可安装的本地应用。沿用已有素材，允许简单静态形状。
形象精修、动画流畅度、跨状态姿态混合、完整视觉录屏、正式公证发布与最低系统矩阵不作为本次完成条件。
每次改动只执行对应的定向检查，不执行全仓测试或全仓代码审查。

本文定义待实现功能；源码核对日期为 2026-09-06。新增命令和路径均为设计内容，尚未形成产品支持声明。
[技术设计](design.md)规定接入和打包方式，[界面与动画规格](ui-design.md)规定视觉交付，
[验收文档](validation.md)规定操作步骤与结果记录。

## 使用场景

开发者让 Codex 持续处理一个 Dev Flow 任务，随后切换到编辑器、浏览器或其他工作。任务进入新阶段、
遇到阻塞或完成时，开发者希望直接在桌面看到变化，并能迅速打开对应任务。

## 当前做法

开发者通过 Codex / DeepSeek 会话或本地 WebUI 查看进度。WebUI 已有任务列表、详情页、流程图和阻塞
信息；查看这些信息仍需打开页面。桌面宠物将所选任务的简要状态常驻显示，并复用详情页完成后续操作。

## 可用数据

现有 HTTP 接口返回任务 ID、摘要、来源 Host、当前节点、revision、更新时间、阻塞说明和归档状态。
详情页支持 `/tasks/{task_id}`。动态 loopback 地址和服务身份由所选 Core 的 WebUI 命令取得。

Core 节点表示最近保存的流程阶段，不能说明 Codex 或 DeepSeek 此刻正在执行、等待输入或已经退出。
桌面组件据此显示阶段，不计算完成百分比或预计剩余时间。

## 处理规则

- 至少一个 Adapter 必须通过现有安装记录、平台和 Core 可执行文件校验；安装统一入口本身不等于具备激活条件。
- 宠物只关注一个任务。用户选定后保持该任务，其他任务的更新不会改变关注对象。
- Core 决定任务阶段、阻塞和终态；宠物决定文案、姿态和页面跳转。
- `BLOCKED` 显示“暂时受阻”与已有原因，不统一解释成等待批准。
- 连续在线观察到所选任务从非终态进入 `DONE` 时庆祝一次；`CANCELLED` 不庆祝。
- 启动、切换任务、重新显示、系统唤醒和断线恢复后的首次读取只建立当前画面，不重放历史提示。
- 更新和气泡展开保持其他应用的键盘焦点。点击打开任务，拖动结束不触发跳转。
- 停止宠物保留共享 WebUI、Host 会话和任务；维护正在使用的 Adapter 时先停止宠物，下次开启重新选择运行时。

这些行为只使用已有 Task 和本地接口，不新增 Core 流程节点、转换或用户工作步骤。

## 预期效果

宠物停留在桌面角落，上方常驻任务简称和阶段两行信息。悬停展开更新时间、最近同步时间及阻塞说明。
单击进入当前任务详情，拖动调整位置，菜单栏提供选择任务、打开任务列表、重试连接、动画开关、
隐藏/显示和退出。右键复用同一组入口；语言跟随系统，以简体中文和英文提供界面。

沿用已有五类素材，任务与连接信息以文字为准。动画开关与系统减少动态效果设置提供静态展示方式；
功能验收检查开关、事件取消和终态提示规则，视觉表现不影响本次功能完成判断。

## 风险与影响

将旧记录显示为实时执行状态可能让用户误判任务仍在推进，遗漏阻塞提示会延迟处理。宠物分别显示
“任务更新于”和“最近同步”；连接失败时标明“上次记录”，停止工作和庆祝动画。

打开旧地址可能进入错误服务。跳转前重新检查 Core 身份、数据目录和 loopback 地址，任务操作仍在
WebUI 内使用其现有检查。素材质量差、动作突跳或窗口抢焦点会影响日常使用，须同时验收画面与实际交互。

## 安装和生命周期

原生产物为 `DevFlowPet.app`，在统一入口的 npm 包中只携带一份。用户通过现有 Dev Flow 安装流程取得
Adapter，再从统一入口开启宠物；只安装 Adapter 的用户需要先取得统一入口。应用在包内运行，更新跟随
统一入口，用户无需另装 DMG、PKG 或应用商店产品，也无需安装 Swift/Xcode。

该分发方式参考 [node-notifier](https://github.com/mikaelbr/node-notifier) 在 npm 包内携带
`terminal-notifier.app` 的做法。桌面窗口和动画由 Dev Flow 自己实现。

下列命令是本需求拟新增的用户入口：

| 入口 | 行为 |
| --- | --- |
| `dev-flow pet start` | 校验已安装 Adapter，必要时通过现有 Core 启动 WebUI，再显示宠物；同一 Core 与数据目录的已运行实例恢复显示 |
| `dev-flow pet stop` | 停止当前用户身份匹配的宠物；已经停止时成功返回 |
| `dev-flow` 交互菜单 | 提供桌面宠物的开启和关闭，复用相同编排 |

命令返回简短文本和退出码。宠物的连接状态直接显示在气泡中；不提供 `pet status`、宠物 JSON 查询接口
或独立管理面板。只有显式开启或重试操作可以请求启动 WebUI，后台轮询不反复启动用户停止的服务。

统一入口升级、修复、重装或移除当前供给 Core 的 Adapter 前，停止与其匹配的宠物。停止失败时保留
Adapter，允许重试；已确认的 factory-reset 在清理前停止宠物。外部工具直接移除 Adapter 或改变 Core
身份时，宠物在后续检查中退出，用户重新开启即可选择仍可用的 Adapter，不做运行中的自动切换。

普通退出、Adapter 卸载及统一入口更新保留宠物偏好。factory-reset 将 `productRoot/pet` 纳入既有确认计划和清理目标，与配置、默认数据和已确认显式数据一起处理。

## 任务选择和状态展示

启动时恢复当前 `data_root_digest` 对应的任务 ID。没有保存选择时，从 `lifecycle=blocked` 第一页
选择最近更新的任务，再尝试 `lifecycle=active`；两者为空时待机。保存的任务已归档或不存在时显示该
结果，由用户切换，不静默换成另一任务。

选择面板按需调用 `GET /api/tasks?page=...`，展示任务摘要、来源工具、阶段和仓库提示，按 `has_next`
加载下一页。接口每页最多 50 条，默认排除归档任务。宠物不在后台遍历所有任务。

| 读取结果 | 展示与动作 |
| --- | --- |
| 普通节点 | 显示现有 WebUI 节点名称，使用普通阶段动画；节点回退直接显示新的当前值 |
| `BLOCKED` | 受阻动画与具体原因；同一阻塞的普通 revision 更新不重放提示动作 |
| `DONE` | 按连续观察规则庆祝一次，随后保持完成姿态 |
| `CANCELLED` | 已取消文案与平静静态姿态 |
| 详情 `readiness=read_only` | 保留阶段，增加“当前仅可查看”提示 |
| 无任务 / 已归档 / 不存在 | 分别显示选择任务、已归档或任务已不可用；不存在时点击打开任务列表 |
| 请求失败 / 身份不符 | 显示未连接与上次记录，切换未连接动画；身份变化要求重新开启 |

连接、任务和提示优先级、轮询取消与动画触发规则详见技术设计，动作内容详见界面与动画规格。

## 验收方式

验收对象是从最终 npm tarball 安装的应用。完整步骤及结果位置见[验收文档](validation.md)。

| 场景 | 通过条件 | 验证方式 |
| --- | --- | --- |
| 激活条件 | 无可用 Adapter 无法激活；Codex-only、DeepSeek-only 和两者共存均可启动 | 启动器定向测试及原生安装检查 |
| 桌面交互 | 可见、拖动不误跳转、更新不抢焦点、隐藏可恢复、退出无残留窗口 | macOS arm64 原生检查 |
| 任务变化 | 正确显示前进、回退、受阻、恢复、完成和取消；没有伪造运行状态或完成比例 | 展示测试及实际 Codex 任务流程 |
| Host 共用数据 | DeepSeek 创建的任务可选择、更新和跳转，使用同一展示规则 | 实际 DeepSeek 任务检查 |
| 连接与选择 | 端口变化后打开正确页面；旧请求不覆盖新选择；重连不重放完成动画 | HTTP 定向测试及原生服务启停 |
| 视觉与动画 | 原创形象与全部五类动画完成，循环和转场自然，透明边缘、缩放、静态模式合格 | 素材预览及安装后应用录屏 |
| 生命周期与包 | 重复启动单实例，维护 Adapter 前停止宠物，reset 覆盖设置，解包后签名和资源有效 | 定向生命周期与最终包检查 |

## 非目标

- Windows、Linux、Intel Mac、跨机器桌面组件；现有 Dev Flow 平台能力保持原范围。
- 无 Adapter 独立运行、自动安装 Adapter、运行中自动切换 Core、独立安装器或自动更新器。
- Codex 内置宠物控制、Host 私有会话数据库或内部事件监听。
- 在宠物中创建任务、提交 Action、解除 blocker、批准测试或执行 Git 操作。
- 新 Core 节点、转换、MCP 工具、Task 字段、SQLite 布局或历史配置兼容处理。
- 全量后台监控、预计时间、完成百分比、登录自启、云同步、语音、养成或皮肤市场。
- 独立设置窗口、手工语言切换，以及为各类全屏应用制作特殊窗口适配。
